5. Intégration Stripe — étapes

⚠ Action requise : Le formulaire Stripe est déjà intégré dans paiement.html. Il manque uniquement votre clé publique côté frontend, et la création du PaymentIntent côté serveur.

Étape 1 — Obtenir vos clés Stripe

  1. Créer un compte sur stripe.com
  2. Dashboard → Développeurs → Clés API
  3. Copier la clé publiable (pk_live_…)
  4. Copier la clé secrète (sk_live_…) — ne jamais l'exposer en frontend

Étape 2 — Remplacer dans paiement.html

const STRIPE_PUBLIC_KEY = 'pk_live_VOTRE_CLE_ICI';

Étape 3 — Créer le PaymentIntent côté serveur

// Node.js / Express

6. Emails transactionnels — Brevo

  1. Créer un compte sur brevo.com (gratuit jusqu'à 300 emails/jour)
  2. Récupérer votre clé API Brevo
  3. Importer le template email-confirmation.html dans Brevo → Templates
  4. Remplacer les variables {"{{ORDER_ID}}"}, {"{{ORDER_LINES}}"}, {"{{TOTAL}}"} par les variables Brevo correspondantes
  5. Appeler l'API Brevo depuis votre backend après chaque commande confirmée :
POST https://api.brevo.com/v3/smtp/email
Authorization: api-key VOTRE_CLE_BREVO

7. Authentification admin sécurisée

⚠ Actuel : Le login utilise sessionStorage — contournable. Pour la production, implémenter JWT côté serveur.
  • Hasher le mot de passe avec bcrypt (salt 12)
  • Générer un JWT signé avec jsonwebtoken à la connexion
  • Stocker le token dans httpOnly cookie (protection XSS)
  • Vérifier le JWT sur chaque requête admin via middleware Express
  • Durée de session recommandée : 8h avec refresh token
